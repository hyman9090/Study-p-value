# Study p-value：用班級身高學假設檢定

一個超簡單嘅 Python 練習：用「一班同學嘅身高」做真實場景，
一步步計出 **p-value**，學識統計學入面「拒絕 H0」到底係咩意思。

## 呢個 project 比較緊咩？

場景係咁：

- 有報告話香港 18 歲男生**平均身高 168 cm**。
- 你量咗自己班 **20 個男同學**嘅身高。
- 你發現佢哋平均有 **171.05 cm**，高過 168 cm。

問題：**呢 3 cm 差距，係真係有分別，定只係抽樣撞彩？**

可能你班同學真係高啲；亦可能只係咁啱抽到班高佬。
假設檢定就係幫你分辨呢兩個可能。

## 咩係 p-value？

> **p-value = 假設「其實冇分別」（H0 係真），
> 純粹靠運氣都見到而家咁大（或更大）差距嘅機率。**

生活化諗法：

- 你同朋友擲銀仔，佢連續 10 次都係公。
- 如果個銀仔係公平（冇出千），連中 10 次公嘅機率只得 0.1%。
- 呢個機率就係 p-value。機率太細，你就會懷疑：「個銀仔有問題！」

返去身高例子：

- **p 好細（例如 0.000036）**→ 如果真係冇分別，見到咁大差距嘅機率得十萬分之 3.6，實在太巧合 → 我哋**拒絕 H0**，相信班同學真係唔同過全港平均。
- **p 大（例如 0.08）**→ 就算冇分別，撞彩都有 8% 機會見到呢個差距，唔算離譜 → **唔能夠拒絕 H0**，只可以話「冇足夠證據話有分別」。

**判斷線 α = 0.05（5%）**：p 低過 0.05 就當「太巧合，唔信係運氣」。

注意：p-value **唔係**「H0 係真嘅機率」。佢係假設 H0 真之後，數據有幾罕見。

## 咩係 t 值？

**t 值 = 差距係「幾多個標準誤差」咁大。**

公式：

```
        x̄ − μ0          （觀察平均 − 假設平均）
t  =  ─────────
        s / √n           （標準誤差 SE）
```

- `x̄`：你班同學嘅平均身高
- `μ0`：假設嘅全港平均（例如 168）
- `s`：樣本標準差（同學之間身高差幾多）
- `n`：人數；`s/√n` 叫**標準誤差（SE）**，即係「抽 20 個人，個平均數本身會浮動幾多」

t 值大 → 差距大過正常浮動好多 → 唔似係撞彩。
計到 t 之後，用 **t 分佈**（自由度 = n − 1）搵出「見到咁大 t 嘅機率」，就係 p-value。
（樣本細嗰陣用 t 分佈會穩陣過用常態分佈，因為佢條尾厚啲，對巧合保守啲。）

## 單尾 vs 雙尾

分別在 H1 嘅方向：

| | 雙尾（two-tailed） | 單尾（one-tailed） |
|---|---|---|
| H1 | μ ≠ μ0（有分別就得，唔理方向） | μ > μ0 或 μ < μ0（指定方向） |
| 「極端」點計 | 兩邊尾都計，t 好正或好負都算 | 只計一邊尾 |
| p-value | 2 × P(T ≥ \|t\|) | P(T ≥ t) 或 P(T ≤ t)，唔乘 2 |

呢個 project 用雙尾 —— 問嘅係「有冇分別」，冇預設高定矮。

### 對結論嘅影響

同一組數據，H0 = 170 cm：

| | 雙尾 | 單尾（H1: μ > 170） |
|---|---|---|
| p-value | 0.0805 | 0.0403（雙尾除以 2） |
| 結論（α = 0.05） | 唔能夠拒絕 | 拒絕 H0 |

單尾將全部 5% 判斷線擺晒落一邊，唔使兩邊分，所以 p 細一半，power 大啲。

### 單尾兩個方向，拒絕 H0 代表咩

- **右尾**（H1: μ > μ0）拒絕：有足夠證據話真實平均**高過** μ0，唔係抽樣運氣。
  我哋數據行右尾（μ0 = 168）：p = 0.000018 → 拒絕，即「班同學真係高過 168」。
- **左尾**（H1: μ < μ0）拒絕：有足夠證據話真實平均**矮過** μ0。

關鍵：單尾對相反方向係**盲**嘅。揀咗右尾，就算數據明顯低過 μ0，
都唔會拒絕 —— p 會接近 1。因為你事先講明只睇「高過」嗰邊。

| 數據顯示 | 右尾（H1: > 168） | 左尾（H1: < 168） |
|---|---|---|
| x̄ = 171（高過 168） | p = 0.000018，拒絕 | p ≈ 1，唔拒絕 |
| x̄ = 165（矮過 168） | p ≈ 1，唔拒絕 | p 好細，拒絕 |

### 幾時用邊個

- **預設用雙尾**：唔肯定方向，或者相反方向都係重要發現
  （例如新藥可能好可能差，差都要知）。科學研究慣例。
- **單尾**：收集數據**之前**已有強理由只關心一個方向，
  而且相反方向完全冇意義。例：藥廠只想知新藥好唔好過舊藥，差過都當失敗。

**大忌：睇完數據先揀單尾 = 出千（p-hacking）。**
見到 t 係正先話用右尾，p 即刻細一半，假陽性翻倍。
方向必須事先定，仲要講得出理由。

### code 點寫

```python
# scipy
stats.ttest_1samp(HEIGHTS, 170.0, alternative="greater")  # 右尾，H1: μ > 170
stats.ttest_1samp(HEIGHTS, 170.0, alternative="less")     # 左尾，H1: μ < 170

# 手算單尾：唔乘 2
p_one_tail = stats.t.sf(t_stat, df)  # 右尾
```

兩點注意：

1. 拒絕唔係 100% 證實 —— 永遠有 α（5%）機會誤判。
2. 唔拒絕 ≠ H0 係真 —— 只係「冇足夠證據」，唔代表真係相等。

## 成個流程（project 點行）

`src/study_p_value/class_heights.py` 會將下面每一步印晒出嚟：

1. **定假設**
   - H0（虛無假設）：班平均 = 168 cm（冇分別）
   - H1（對立假設）：班平均 ≠ 168 cm（有分別，雙尾）
2. **收集數據**：20 個同學身高（寫死喺 `HEIGHTS`，可以自己改）
3. **計樣本統計**：n = 20，x̄ = 171.05，s = 2.544
4. **計標準誤差**：SE = s / √n = 2.544 / √20 = 0.5688
5. **計 t 值**：t = (171.05 − 168) / 0.5688 = 5.362
6. **計 p-value**：t 分佈（自由度 19）雙尾機率 → p = 0.000036
7. **scipy 驗證**：`stats.ttest_1samp` 計一次，對手算有冇錯
8. **下結論**：p < 0.05 → 拒絕 H0

script 仲會用同一組數據試多一次 **H0 = 170 cm**：

| H0 假設平均 | t 值 | p-value | 結論（α = 0.05） |
|---|---|---|---|
| 168 cm | 5.362 | 0.000036 | 拒絕 H0：有顯著分別 |
| 170 cm | 1.846 | 0.080542 | 唔能夠拒絕：冇足夠證據 |

同一組數據，H0 唔同，結論可以唔同 —— 呢個正正係 p-value 嘅精髓：
佢度緊嘅係「數據同某個具體假設有幾唔夾」。
